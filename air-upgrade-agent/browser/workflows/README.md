# Workflows

The browser workflow (manual login → booking page → read-only observation →
official action only after human confirmation) is implemented in
`backend/app/browser/agent.py` and `backend/app/booking/providers/airfrance.py`,
and documented step by step in `docs/AIR_FRANCE_WORKFLOW.md`.

The simulated airline page used for end-to-end tests is generated by
`backend/app/browser/mock_page.py` from `data/mock/scenarios.json`.
